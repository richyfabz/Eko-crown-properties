# Ecko properties Real Estate Platform

Premium React + TypeScript real estate experience for Nigerian buyers, renters, sellers, and diaspora clients.

## Stack

- React
- TypeScript
- Vite
- Framer Motion

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`
- `npm run test`

## Folder Overview

- `src/components` shared UI building blocks
- `src/features` feature-specific logic and composite UI
- `src/data` typed sample content
- `src/types` domain types
- `src/animations` motion tokens and variants
- `src/styles` global styling
- `public/images` copied local assets used by the app

## Asset Policy

The repo reuses provided image assets from the original `img/` folder. Source files should keep meaningful alt text and avoid fabricating credibility or using placeholder trust content.

## Known Limitations

- No backend or CMS is connected yet.
- Some contact, booking, and seller flows use front-end submission states only.
- Sample data is clearly labeled where it stands in for real inventory.

## Deployment Notes

The app is built for static deployment after the production build succeeds.

------------------------------------------------------------
0. PURPOSE
------------------------------------------------------------

The Design System defines every visual rule required to build a
premium Nigerian real estate experience.

It is not merely a UI kit.

It is the visual language of the product.

Every designer,
developer,
and AI implementation agent should follow this document to ensure visual consistency.

The Design System exists to answer:

• How should the interface look?

• How should components behave visually?

• How should spacing feel?

• How should typography communicate hierarchy?

• How should photography be presented?

• What should premium look like?

79. DESIGN TOKENS
------------------------------------------------------------

Design tokens are the single source of truth for the visual system.

Never hardcode visual values inside components.

Use centralized tokens for:

Colors

Typography

Spacing

Radius

Borders

Elevation

Animation

Opacity

Breakpoints

Z-index

Transition durations

Every component should consume tokens instead of defining its own values.
